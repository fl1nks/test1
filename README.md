# Сайт фотографа Ольги Руденковой

Полноценный сайт с админ-панелью для частного фотографа: публичная часть (главная, услуги, портфолио, контакты с формой заявки) и панель управления контентом без программиста.

Реализовано по уставу проекта «Разработка и внедрение сайта для фотографа» (менеджер проекта — Малашенко И. С., заказчик — Руденкова О. Е.): адаптивная вёрстка, каталог услуг с ценами, портфолио по категориям, приём заявок, управление услугами/портфолио/контактами через админ-панель.

## Стек

- **Next.js 14** (App Router) + **React 18** + **TypeScript**
- **Tailwind CSS** — дизайн-система (тёплая «бумажная» палитра, Playfair Display + Cormorant Garamond + Inter, кириллица)
- **База данных** — встроенный SQLite (`node:sqlite` из Node.js 22+), файл `data/site.db` — ничего не нужно устанавливать
- Своя авторизация в админке (HMAC-сессия, httpOnly cookie, защита от брутфорса)
- Ноль платных сервисов и подписок — соответствует бюджету устава (10 000 ₽)

## Требования

- Node.js **22.5+** (нужен встроенный модуль `node:sqlite`)

## Быстрый старт

```bash
npm install
npm run build
npm run start          # http://localhost:3000  (PORT=8080 npm run start — другой порт)
```

Для разработки: `npm run dev`

Сайт: `/` · Услуги: `/uslugi` · Портфолио: `/portfolio` · Контакты и заявка: `/contacts`
Админ-панель: **`/admin`** — пароль по умолчанию: **`olga2026`** (смените через `ADMIN_PASSWORD`!)

## Переменные окружения

См. `.env.example`. Файл `.env` не коммитится. Перед публикацией обязательно задайте `ADMIN_PASSWORD` и `SESSION_SECRET`.

## Что где лежит

```
app/                 страницы (публичные + /admin) и route handler /files/*
components/site/     шапка, подвал, галерея портфолио, форма заявки и т.д.
components/admin/    оболочка и разделы админ-панели
lib/                 база (db.ts), запросы (queries.ts), авторизация (auth.ts)
data/                site.db и загруженные в админке фото (uploads/) — не в git
public/images/       сгенерированные изображения-заглушки (замените своими в админке)
ИНСТРУКЦИЯ.md        инструкция по управлению контентом для фотографа
```

## Данные

При первом запуске база создаётся и наполняется демо-контентом (прайс, категории портфолио, тексты). Ваши правки из админки имеют приоритет и не перезатираются.

**Резервная копия** = скопировать `data/site.db*` и `data/uploads/`.

## Возможности админ-панели

- **Услуги**: добавление / редактирование / удаление, скрытие с сайта, порядок, бейджи («Хит», «Премиум»)
- **Портфолио**: загрузка фото (drag&drop, JPG/PNG/WebP до 12 МБ), категории — добавление, переименование, удаление, перемещение фото между категориями
- **Заявки**: все обращения с формы — имя, контакт, услуга, комментарий; статусы «Новая / В работе / Закрыта»
- **Контакты и тексты**: имя фотографа, подзаголовки главной, «Обо мне», телефон, Telegram/WhatsApp/VK/почта, адрес студии, режим работы, зона выездной съёмки

## Что сознательно НЕ входит (по уставу, п. 2.3)

Нативные приложения · онлайн-оплата · мультиязычность · личный кабинет клиента · интеграция с системами обработки и доставки фото.

## Деплой на хостинг

Любой VPS с Node.js 22+: установить зависимости, `npm run build`, запуск через systemd/pm2 (`npm run start`) за реверс-прокси (nginx) с HTTPS. Подробно — в разделе «Размещение в интернете» файла `ИНСТРУКЦИЯ.md`.
