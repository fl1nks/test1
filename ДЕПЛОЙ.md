# Как запустить сайт и выложить его в интернет

Инструкция для Ольги. Разделы: (1) запуск на своём компьютере, (2) что купить для публикации, (3) как сайт ставится на хостинг, (4) что прислать, чтобы выложил разработчик.

---

## 1. Запустить сайт на компьютере

**Что нужно один раз:** Node.js версии **22 или новее** (именно так, потому что база данных — встроенный SQLite Node).

1. Установите Node.js LTS: https://nodejs.org — большая кнопка «LTS». Проверьте установку: откройте терминал (Windows: «Пуск → cmd») и напишите `node -v` — должно быть что-то вроде `v22.x.x`.
2. Скачайте сайт, один из двух вариантов:
   - если установлен Git: `git clone -b arena/6dac4960-test1 https://github.com/fl1nks/test1.git`
   - иначе: на странице репозитория кнопка **Code → Download ZIP**, распакуйте архив.
3. Откройте терминал в папке проекта и выполните:
   ```
   npm install
   ```
   (один раз, займёт пару минут)
4. Запуск:
   - для разработки: `npm run dev` → сайт откроется на http://localhost:3000
   - «как на сервере»: `npm run build` и затем `npm start` → тоже http://localhost:3000
5. Админка: **http://localhost:3000/admin**
   Пароль по умолчанию: `olga2026` — смените через `ADMIN_PASSWORD` (см. `.env.example`).

**Где лежат данные:** файл `data/site.db` (заявки, услуги, настройки) и папка `data/uploads/` (загруженные фото). Это просто файлы — их можно копировать как обычные файлы.

## 2. Что купить, чтобы сайт был в интернете

| Что | Зачем | Где и сколько (примерно) |
|---|---|---|
| **VPS** (виртуальный сервер) | Сам сервер, на котором крутится сайт | FirstVDS, Timeweb, reg.ru, Selectel, RUVDS… **~150–400 ₽/мес**. При заказе: Ubuntu 22.04/24.04, 1 vCPU, 1–2 ГБ RAM — достаточно |
| **Домен** | Адрес сайта вместо набора цифр | Рег.ру, NIC.RU, сами VPS-провайдеры… **~150–300 ₽/год** за `.ru`. По желанию: без домена сайт тоже откроется по IP, но «нормальным» он будет с доменом |
| **SSL-сертификат** | Замочек и https | **Бесплатно** (Let's Encrypt), настраивается одной командой на сервере |

Альтернатива VPS: хостинг с Node.js поддержкой — но у «обычного» виртуального хостинга почти всегда нет Node, поэтому VPS проще и надёжнее.

## 3. Как сайт ставится на VPS (шпаргалка)

Команды выполняются на сервере по SSH (подключается разработчик: `ssh root@<IP сервера>`).

```bash
# 1. Node.js 22 и git
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs git

# 2. Код сайта
git clone -b arena/6dac4960-test1 https://github.com/fl1nks/test1.git /var/www/site
cd /var/www/site
npm install

# 3. Настройки (пароль админки и секреты!)
cp .env.example .env
nano .env
#   ADMIN_PASSWORD=<надёжный пароль, не olga2026!>
#   SESSION_SECRET=<openssl rand -hex 32>
#   NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru

# 4. Сборка и автозапуск
npm run build
npm i -g pm2
pm2 start npm --name kurdenkova-site -- start
pm2 save && pm2 startup   # сайт поднимется сам после перезагрузки сервера

# 5. Домен + https (через nginx и certbot)
apt-get install -y nginx certbot python3-certbot-nginx
#    в DNS домена: A-запись → IP сервера; подождать 5–30 минут
certbot --nginx -d ваш-домен.ru
```

**Перенос данных с компьютера на сервер** (чтобы не потерять заявки и настройки):
скопируйте файлы `data/site.db` и папку `data/uploads/` в `/var/www/site/data/` на сервере. При крупных обновлениях просто повторяйте: `data/site.db` + `data/uploads/` — это и есть вся «база».

**Резервная копия:** раз в месяц копировать те же два объекта в надёжное место (диск, облако). Ничего больше не нужно.

---

## 4. Что прислать разработчику, чтобы сайт выложили

1. **IP-адрес VPS** и **логин/пароль (или SSH-ключ)** — для входа на сервер;
2. **Домен** и доступ к его DNS (запись A на IP сервера);
3. **Желаемый пароль администратора** сайта (вместо olga2026) и, по желанию, адрес почты, на который должны приходить заявки.

Дальше разработчик разворачивает сайт по списку из раздела 3, проверяет форму заявки, админку, включает https и автозапуск — и сайт доступен в интернете.

> ⚠️ Никогда не публикуйте пароль админки и пароль от сервера открыто — только лично разработчику.
